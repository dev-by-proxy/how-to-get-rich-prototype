# How to Get Rich: test prototype

A clickable prototype of the new Month screen, used for usability tests. **Every person and number in it is made up** ("Mei").
No sign-in, no server, no data collection.

- Live: https://dev-by-proxy.github.io/how-to-get-rich-prototype/ (GitHub Pages from `main`).
- Source: `index.html` (edit this one, then commit and push; Pages updates in about a minute).
- Test days: tap the yellow "Demo" chip, or add `#mid-march`, `#end-april`, `#end-may` or `#setup` to the address.
- Never put real names, amounts or keys in this repo: it is public.
